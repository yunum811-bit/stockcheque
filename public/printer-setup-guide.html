คู่มือตั้งค่ากระดาษ Epson LQ-310

สำหรับพิมพ์เช็ค และ ใบนำฝาก (Pay-in) — บริษัท ซีเรียล แฟคตอริ่ง (ประเทศไทย) จำกัด

ภาพรวม

เครื่อง Epson LQ-310 เป็น Dot Matrix Printer ที่ใช้กระดาษต่อเนื่อง/ใบฟอร์มสำเร็จรูป ต้องตั้งค่าขนาดกระดาษ (Custom Paper Size) ให้ตรงกับใบฟอร์มจริงที่ใส่ในเครื่อง

ขนาดกระดาษที่ใช้:
ประเภทฟอร์ม ขนาดจริง (กว้าง x สูง) ชื่อ Form ที่สร้าง แนวกระดาษ
เช็ค BBL / UOB / BAY 210 x 76 mm Cheque_BBL แนวตั้ง (Portrait)
ใบนำฝาก ธ.กรุงไทย (KTB) 210 x 100 mm PayIn_KTB แนวตั้ง (Portrait)
ใบนำฝาก ธ.ยูโอบี (UOB) 210 x 140 mm PayIn_UOB แนวตั้ง (Portrait)
ใบนำฝาก ธ.กรุงเทพ (BBL) 210 x 148 mm PayIn_BBL แนวตั้ง (Portrait)

ขั้นตอนที่ 1: สร้าง Custom Paper Size ใน Windows

1 กดปุ่ม Windows + R พิมพ์ control printers แล้วกด Enter
2 คลิกที่ Epson LQ-310 ให้ highlight (คลิก 1 ครั้ง)
3 ไปที่เมนูด้านบน → File → Print server properties
(ถ้าไม่เห็นเมนู File ให้กดปุ่ม Alt ก่อน)
4 เลือกแท็บ Forms
5 ติ๊ก ☑ Create a new form
6 กรอกค่าตามตารางด้านล่าง → กด Save Form
7 ทำซ้ำข้อ 5-6 สำหรับฟอร์มอื่นๆ ทั้งหมด
ค่าที่ต้องกรอก (สร้างทีละอัน):
Form name Width Height Margins
Cheque_BBL 21.00 cm 7.60 cm ทั้งหมด = 0
PayIn_KTB 21.00 cm 10.00 cm ทั้งหมด = 0
PayIn_UOB 21.00 cm 14.00 cm ทั้งหมด = 0
PayIn_BBL 21.00 cm 14.80 cm ทั้งหมด = 0
💡 หลักการ:
Width = ด้านที่กระดาษป้อนเข้าเครื่อง = ด้านยาว (210mm)
Height = ด้านสั้นของฟอร์ม (76-148mm)
กระดาษป้อนด้าน 210mm เข้าเครื่อง → หัวพิมพ์วิ่งตามแนวสั้น

ขั้นตอนที่ 2: ตั้งค่า Default (ทำครั้งเดียว)

1 คลิกขวาที่ Epson LQ-310 → เลือก Printing Preferences
2 แท็บ Paper/Quality หรือ Layout
3 Paper Size → เลือก Form ที่ใช้บ่อยที่สุด (เช่น PayIn_BBL)
4 Orientation → Portrait (แนวตั้ง)
5 กด OK

ขั้นตอนที่ 3: ใช้งานจริง (ทุกครั้งที่พิมพ์)

1 กรอกข้อมูลในโปรแกรม Stock Cheque
2 ตั้งค่าในโปรแกรม:
  • กว้างกระดาษ / สูงกระดาษ → ตามตาราง
  • แนวกระดาษ → แนวนอน (Landscape)
3 กดปุ่ม "พิมพ์ลงฟอร์ม"
4 ในหน้า Print Dialog:
  • Printer → เลือก Epson LQ-310
  • กด Preferences/Properties
  • Paper Size → เลือก Form ที่ต้องการ (เช่น Cheque_BBL)
  • Orientation → Portrait (แนวตั้ง)
  • กด OK → กด Print
ค่าในโปรแกรมที่ต้องตั้ง:
พิมพ์อะไร กว้าง (mm) สูง (mm) แนวกระดาษ เลือก Form ใน Printer
เช็ค BBL / UOB 210 76 แนวตั้ง Cheque_BBL
Pay-in กรุงไทย 210 100 แนวตั้ง PayIn_KTB
Pay-in UOB 210 140 แนวตั้ง PayIn_UOB
Pay-in กรุงเทพ 210 148 แนวตั้ง PayIn_BBL

วิธีใส่กระดาษ

    ┌─────────────────────────────────────┐
    │     Epson LQ-310 (ด้านหน้า)          │
    │                                     │
    │   ← หัวพิมพ์วิ่งทางนี้ (76-148mm) →  │
    │                                     │
    └─────────────────────────────────────┘
                    ↑
                    │  กระดาษป้อนเข้าทางนี้
                    │  (ด้านยาว = Width = 210mm)
                    │
         ┌──────────────────────────────────┐
         │                                  │
         │  ← ด้านยาว 210mm (ป้อนเข้าเครื่อง) →
         │                                  │
         │  ใบ Pay-in / เช็ค                 │  ↕ ด้านสั้น
         │                                  │    (76-148mm)
         │                                  │    = Height
         └──────────────────────────────────┘

ป้อนกระดาษทาง ด้านยาว (210mm) เข้าเครื่อง — หัวพิมพ์จะวิ่งตามแนวสั้น (76-148mm)

แก้ปัญหาที่พบบ่อย

ปัญหาวิธีแก้
พิมพ์ออกมาเล็ก/ใหญ่กว่าฟอร์ม ตรวจสอบว่า Paper Size ใน Printer Preferences ตรงกับค่าในโปรแกรม
ข้อมูลหมุน 90 องศา สลับ Orientation จาก Portrait ↔ Landscape ใน Printer Preferences
ข้อมูลเลื่อนไปทั้งหมด ปรับค่า "เลื่อนลง" / "เลื่อนขวา" ในโปรแกรม หรือกด "ปรับทีละช่อง"
เลขที่บัญชีไม่ตรงช่อง กด "ปรับทีละช่อง" → ปรับ "ระยะห่างอักษร" ของช่องเลขที่บัญชี
Width/Height สลับกัน สำหรับ Dot Matrix: ลองสลับค่า Width ↔ Height ใน Print Server Properties
มีจุดหรือข้อความด้านบน ใน Print Dialog → ปิด "Headers and footers" (More settings)
ตำแหน่งเลื่อนทุกครั้งที่พิมพ์ ตรวจสอบว่ากระดาษใส่ตรง และล้อเลื่อนกระดาษอยู่ตำแหน่งเดิม
⚠️ สำคัญ: ค่าตำแหน่งที่ปรับใน "ปรับทีละช่อง" จะถูกจำไว้ใน Browser ของเครื่องนั้น (localStorage) — ถ้าเปลี่ยนเครื่อง/browser ต้องปรับใหม่

เคล็ดลับ

  • ทดสอบพิมพ์ลงกระดาษเปล่าก่อน แล้วทาบกับฟอร์มจริงเพื่อดูตำแหน่ง
  • ใช้ปุ่ม "ดูตำแหน่ง" เพื่อดู preview ว่าข้อมูลจะอยู่ตรงไหน
  • ใช้ปุ่ม "ปรับทีละช่อง" เพื่อปรับ field อิสระ (ไม่ต้องเลื่อนทั้งหมด)
  • ค่า "ระยะห่างอักษร" ใช้กับเลขที่บัญชีที่ต้องใส่ทีละช่อง
  • ค่า "ระยะขีดที่ 1/2" ใช้ปรับระยะระหว่างส่วนของเลขที่บัญชี เช่น 024-7-090988
