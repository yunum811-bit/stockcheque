ขั้นตอนที่ 1: สร้าง Custom Paper Size ใน Windows

1 กด Windows + R → พิมพ์ control printers → Enter
2 คลิกที่ Epson LQ-310 ให้ highlight
3 เมนูด้านบน → File → Print server properties (กด Alt ถ้าไม่เห็นเมนู)
4 แท็บ Forms → ติ๊ก ☑ Create a new form
5 กรอกค่าตามตาราง → กด Save Form (ทำทีละอัน)

ขั้นตอนที่ 2: ตั้งค่า Printer Preferences

1 คลิกขวาที่ Epson LQ-310 → Printing Preferences
2 Paper Size → เลือก Form ที่ใช้บ่อย
3 Orientation → Landscape (แนวนอน)
4 กด OK
⚠️ สำคัญ: ต้องตั้ง Landscape เสมอ!
ถ้าตั้ง Portrait ข้อมูลจะหมุน 90 องศา (ตัวอักษรเป็นแนวตั้ง)

ขั้นตอนที่ 3: ใช้งานจริง (ทุกครั้งที่พิมพ์)

1 กรอกข้อมูลในโปรแกรม
2 ตั้งค่าในโปรแกรม (กว้าง/สูง) ตามตาราง
3 กด "พิมพ์ลงฟอร์ม"
4 ในหน้า Print Dialog:
  • Printer: Epson LQ-310
  • กด More settings หรือ Preferences
  • Paper Size: เลือก Form ที่ตรงกัน
  • Orientation: Landscape
  • ☐ ปิด Headers and footers
  • Margins: None (ถ้ามีให้เลือก)
  • กด Print

แก้ปัญหาที่พบบ่อย

ปัญหาสาเหตุวิธีแก้
ข้อมูลหมุน 90 องศา Orientation ตั้งเป็น Portrait เปลี่ยนเป็น Landscape
ข้อมูลบางส่วนหายไป ตำแหน่งตกขอบกระดาษ ตรวจสอบค่า กว้าง/สูง ในโปรแกรมตรงกับ Form ใน Printer
ข้อมูลเลื่อนทั้งหมด ตำแหน่งเริ่มต้นไม่ตรง ใช้ "ปรับทีละช่อง" เลื่อน top/left
มีจุดดำหรือข้อความเกิน Browser พิมพ์ header/footer ปิด "Headers and footers" ใน Print Dialog
ขนาดไม่ตรง Paper Size ใน Printer ไม่ตรง เลือก Custom Form ที่สร้างไว้ ไม่ใช่ A4/Letter
ตำแหน่งเลื่อนทุกครั้ง กระดาษใส่ไม่ตรง จัดกระดาษให้ชิดขอบเดิมทุกครั้ง

เคล็ดลับ

  • ทดสอบพิมพ์ลง กระดาษเปล่า ก่อน → ทาบกับฟอร์มจริง → ปรับตำแหน่ง
  • ใช้ปุ่ม "ปรับทีละช่อง" ปรับแต่ละ field แยกอิสระ (ค่าจำไว้ใน server)
  • ฟอนต์ที่ใช้: AngsanaUPC ขนาด 16pt
  • วันที่ในเช็ค: พิมพ์แยก 8 ตัว (DD MM YYYY) ช่องละ 6.25mm รวม 50mm
  • Offset ใน Printer: ตั้ง 0 ทั้งหมด (ปรับจากโปรแกรมอย่างเดียว)
